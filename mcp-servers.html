MCP Servers for AI Agents

Let AI agents like Claude work safely inside Odoo and Microsoft 365.

Book a demoChat on WhatsApp

Model Context Protocol (MCP) servers connect AI agents to your business systems. Our Odoo server gives read and write access to Odoo data and actions. Our Microsoft 365 server covers Outlook, Teams, SharePoint and calendar actions, with more capabilities than the standard Microsoft 365 MCP connector.

Features

What it does

Odoo MCP server

Read and write Odoo records and run Odoo actions from an AI agent.

Microsoft 365 MCP server

Outlook, Teams, SharePoint and calendar actions in one server.

More than the standard connector

Covers actions the standard Microsoft 365 MCP connector does not.

Works with Claude and others

Any MCP-compatible AI agent can use the tools.

Safe by design

Each tool is scoped so agents only do what you allow.

Built and maintained by us

Python servers we deploy, document and support.

Questions we hear often

What is MCP?

Model Context Protocol is an open standard that lets AI agents use tools and data in other systems in a controlled way.

Can the agent change data in Odoo?

Yes, if you allow it. The Odoo server supports read and write access, scoped to what you approve.

Which AI agents does it work with?

Claude and any other AI agent that supports MCP.
